A single-file Python program that draws a newspaper front page summing up
the world news of Tuesday 17 November 2026 in one 1024x1024 PNG: the record
Ukrainian drone storm that felled the Crimean Bridge span while Russia
pounded Kyiv's bridges, US strikes on Qeshm Island, Iran's drones over the
Gulf, France's strike day, Wall Street's fourth straight fall, Nvidia's
earnings beat, COP31 finance talks and NASA's Voyager 1 light-day eve.
All headlines are drawn from Reuters, AP and NASA reporting of that day
(see NEWS-v1.md). The PNG is encoded by hand (zlib + struct) with a 5x7
bitmap font — standard library only, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
